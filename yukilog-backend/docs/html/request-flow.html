🔄 请求处理流程

示例：POST /api/admin/posts 创建文章

1
🌐 Request 到达
HTTP
POST /api/admin/posts
携带 Authorization: Bearer <token>
JSON Body
2
🔑 AuthGuard 验证
Middleware
解析 Bearer Token
验证 JWT 签名
注入 Claims { user_id: 1, role: "admin" }
3
👑 AdminGuard 检查
Middleware
检查 role == "admin"
✓ 通过
4
📥 Handler 处理
api/http/admin
解析 JSON → CreatePostInput
从 Extensions 取 Claims
调用 post_service.create(input, user_id)
5
⚙️ PostService::create
core/posts
📝 业务逻辑执行
1 验证 category_id 存在
2 验证所有 tag_ids 存在
3 开启数据库事务
4 插入 posts 表
5 批量插入 post_tags 关联表
6 提交事务
6
📤 构造响应
Handler
封装 ApiResponse<PostDetail>
7
✅ Response 返回
HTTP 201
{ "code": 0, "message": "success", "data": { "id": 42, "title": "Hello World", "slug": "hello-world", "status": "published", ... } }
📊 请求经过的层级
🛡️
Middleware
认证 & 授权
📥
Handler
请求解析 & 响应
⚙️
Service
业务逻辑
🗄️
Repository
数据持久化
