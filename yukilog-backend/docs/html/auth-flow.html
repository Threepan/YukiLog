📋 详细步骤说明
1

客户端发起登录请求

POST /api/auth/login
携带 { username, password }

2

Handler 解析请求

提取 JSON Body，验证必填字段

3

调用 AuthService

auth_service.login(username, password)

4

查询数据库

Repository 查找用户记录
返回含 password_hash

5

验证密码 & 签发 JWT

Argon2 验证密码
生成 Access + Refresh Token

6

返回 Token

{ access_token, refresh_token, expires_in }
